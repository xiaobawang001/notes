# 静态博客站功能文档

> 来源：`xiaobawang001.github.io-master` 项目分析
> 日期：2026-07-22

---

## 技术栈

- **框架**: VitePress ^1.6.3（静态站点生成器）
- **UI 库**: Element Plus ^2.14.3
- **图标**: Lucide Vue ^1.24.0
- **图表**: Mermaid ^11.16.0, Graphviz, PlantUML
- **部署**: GitHub Pages

## 2. 功能清单

### 2.1 导航栏功能（从左到右）

| 功能 | 说明 |
|------|------|
| **站点头像** | 圆形头像图片，旁边跟着站点标题「xiaobawang001」 |
| **搜索框** | VitePress 内置搜索（支持中文分词、模糊匹配、前缀搜索），点击弹出搜索模态框 |
| **字号切换** | 小/中/大 三档切换，通过 CSS 变量控制 `--blog-doc-font-size`，持久化到 localStorage |
| **阅读宽度** | 窄/中/宽 三档，控制 `.content-container` 的 `max-width`，持久化到 localStorage |
| **专注模式** | 点击隐藏侧边栏和右侧目录，只保留正文 |
| **深色/浅色切换** | VitePress 内置，跟随系统偏好 |
| **菜单链接** | 发布指南、GitHub 仓库链接 |

### 2.2 侧边栏

| 功能 | 说明 |
|------|------|
| **工具栏** | 固定在侧边栏顶部，包含「文档目录」标题 + 定位当前文档按钮 + 展开/折叠全部目录按钮 |
| **目录树** | 从 `sidebar-tree.yaml` 生成，支持多级嵌套 |
| **文件夹图标** | 黄色文件夹 SVG 图标 |
| **文件图标** | 灰色文档 SVG 图标 |
| **缩进线** | 语雀风格细线缩进 |
| **展开/折叠** | 点击文件夹可展开/折叠子项 |
| **状态持久化** | 侧边栏展开/折叠状态持久化到 localStorage |
| **选中高亮** | 当前文档绿色背景 + 绿色加粗文字 |
| **路径高亮** | 父级目录在展开时也显示绿色高亮 |
| **全部折叠** | 工具栏按钮一键折叠所有目录 |

### 2.3 正文阅读区（白色「纸张」卡片）

| 功能 | 说明 |
|------|------|
| **白色卡片** | 内容区呈现在白色背景卡片中，有圆角和阴影，像语雀的阅读体验 |
| **面包屑** | NavBreadcrumb 组件显示当前路径层级 |
| **文章标签** | DocTags 组件，显示文档标签（从 frontmatter 提取） |
| **Markdown 排版** | 完整的 h1-h6、p、blockquote、table、code 排版 |
| **标题锚点分享** | 鼠标悬停标题时显示分享按钮，点击复制标题链接到剪贴板 |
| **代码块增强** | 语言标签 + 复制代码 + 换行切换 + 折叠展开 + 行号 + 行高亮 |
| **图片点击放大** | 使用 ImageZoom 组件 |
| **Mermaid 图表** | 支持 mermaid 代码块渲染 |
| **Graphviz 图表** | 支持 graphviz 代码块渲染 |
| **PlantUML 图表** | 支持 plantuml 代码块渲染 |
| **文内搜索** | InPageSearch 组件，在文章内搜索关键词并高亮 |
| **底部导航** | 上一篇/下一篇文档 |
| **编辑链接** | 在 GitHub 上编辑此页 |
| **最后更新时间** | 显示文档最后更新日期 |
| **相关阅读** | RelatedArticles 组件，推荐最多 5 篇相关文章 |

### 2.4 右侧目录（Aside）

| 功能 | 说明 |
|------|------|
| **文章目录** | 固定右侧，显示 h2-h4 标题层级 |
| **工具栏** | OutlineToolbar 显示「文章目录」标题 |
| **滚动跟随** | 阅读时当前标题高亮并自动滚动 |
| **空状态** | 无目录时显示「无目录」占位 |

### 2.5 全局功能

| 功能 | 说明 |
|------|------|
| **阅读进度条** | 固定在导航栏下方，3px 绿色进度条 |
| **回到顶部** | Element Plus 的 el-backtop 组件，右下角浮动 |
| **深色模式** | 完整的深色模式支持，所有颜色变量适配 `:root.dark` |
| **响应式布局** | 桌面/平板/手机三档适配 |

## 3. 设计主题（语雀风格）

- **品牌色**: `#00b96b`（绿色）
- **页面背景**: `#f4f5f5`
- **卡片背景**: `#ffffff`
- **侧边栏背景**: `#ffffff`
- **字体**: `-apple-system, PingFang SC, Hiragino Sans GB, Microsoft YaHei, ...`
- **内容最大宽度**: 960px（可调）
- **侧边栏宽度**: 280px
- **阴影**: 柔和卡片阴影 `0 1px 4px rgba(0,0,0,0.05), 0 4px 24px rgba(0,0,0,0.04)`

## 4. 与当前 Nuxt 项目的差异对比

| 方面 | 静态站 | 当前 Nuxt 项目 |
|------|--------|----------------|
| 数据源 | 本地 Markdown 文件 | Coze 数据库 API |
| 页面布局 | 侧边栏 + 白色卡片内容 + 右侧目录 | 侧边栏 + 内容区 |
| 导航栏 | 头像 + 标题 + 搜索 + 字号/宽度/专注/主题 | 标题 + 搜索 + 首页/搜索/管理链接 |
| 代码块 | 语言标签、复制、换行、折叠等 CSDN 风格 | 基础 highlight.js 渲染 |
| 右侧目录 | 固定右侧，滚动跟随 | 无 |
| 阅读进度条 | 顶部 3px 绿色条 | 无 |
| 回到顶部 | el-backtop | 无 |
| 字号/宽度/专注模式 | 三档可调 | 无 |
| 标题锚点分享 | 悬停显示，点击复制链接 | 无 |
| 相关阅读 | 基于路径匹配推荐 | 无 |
| 深色模式 | 完整支持 | 无 |
| 图表渲染 | Mermaid, Graphviz, PlantUML | 无 |
| 面包屑 | 支持 | 基础版本 |

## 6. 关键设计变量（CSS 自定义属性）

```css
--yuque-page-bg: #f4f5f5;           /* 页面背景 */
--yuque-paper-bg: #ffffff;           /* 卡片背景 */
--yuque-sidebar-bg: #ffffff;         /* 侧边栏背景 */
--yuque-border: #e7e9e8;            /* 边框 */
--yuque-border-light: #eff0f0;      /* 浅边框 */
--yuque-text: #262626;              /* 主文字 */
--yuque-text-secondary: #8a8f8d;    /* 次要文字 */
--yuque-brand: #00b96b;             /* 品牌色 */
--yuque-brand-soft: rgba(0,185,107,0.1); /* 品牌色柔和版 */
--yuque-shadow-paper: 0 1px 4px rgba(0,0,0,0.05), 0 4px 24px rgba(0,0,0,0.04);
--vp-sidebar-width: 280px;
--blog-content-max-width: 960px;
```
